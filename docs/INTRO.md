# dsh-memory 是什么，以及为什么这样做

> 写给使用者看的。不谈实现细节，只回答三个问题：它替我记住什么、它怎么决定记什么、我该注意什么。

## 一句话

给你的 AI 助手装一个**本地的长期记忆**：聊过的事、你的偏好、定过的方案，下次开新会话它还记得；记忆存在你自己电脑上，默认不联网、不花钱。

## 它解决什么问题

没有记忆的助手，每开一个新会话都从零开始：你昨天说的偏好、上周定的方案、上个月纠正过的错误，全部要重新讲一遍。而把整段历史都塞进上下文，既贵又慢，还会把关键信息淹掉。

dsh-memory 的做法是：**只把「值得长期记住的」提炼出来存好，每次只取相关的几条放回对话里。**

## 它记三层东西

| 层 | 记什么 | 例子 |
|---|---|---|
| 事实 | 原子级、可判真假的一句话 | 「数据目录在 `~/.dsh-memory`」「偏好先看结论再看细节」 |
| 原话 | 你说过的原文片段（可回查） | 「上次关于导出的那段讨论」 |
| 归纳 | 从多条事实里总结的规律 | 「凡是涉及方案，都要求先确认验收标准再动手」 |

事实是主体；原话用于「上次那句话到底怎么说的」；归纳是从多条事实里长出来的，会标记依据条数，过时了会降权并提示「可能已过时」。

## 它怎么决定记什么

1. **默认只用规则**：只认明确句式（「记住…」「以后…」「我的 X 是…」「别再…」）。没命中就不记，**不产生任何费用**。
2. **可选接模型**：填了 API Key 并打开开关后，才会用模型从对话里抽取更自由表述的事实；每次调用约 0.005 元，每月默认封顶 20 元，超了自动退回纯规则。
3. **写入口有闸**：疑问句不记、主语谓语不完整不记、隐私内容不记；助手自己说的话默认不算你的事实。
4. **冲突不硬改**：同一件事被改写时，只有语义足够接近（相似度 ≥ 0.80）才覆盖旧条；不同的事即使谓词相同也并存；拿不准的进「待审」，由你在设置页点通过或驳回。

## 它怎么把记忆放回对话

每轮最多取 6 条、800 字，按相关度排序，放在对话里并标注「这是资料，不是用户本轮发言」。每个会话有次数上限，避免长会话反复注入把上下文撑爆。

## 它会不会变慢、会不会忘

- **检索**：SQLite 全文检索为主；装了本地向量模型就再加一路语义检索，两路结果融合。模型缺失时自动退化为纯全文检索，功能不受影响。
- **遗忘**：按「最近访问 + 访问频次 + 关联度」算一个活力分，长期不用会**降权、归档**，但**绝不自动删除**；归档的可以恢复。你明确交代过的（如「记住…」）不会被归档。
- **不会越记越多到失控**：同簇太多条时，低分的会被降权；归纳按需重算，默认不自动跑。

## 隐私与花费

- 所有数据在 `~/.dsh-memory`：事实是 markdown，索引是 SQLite，随时能看、能备份、能整目录搬走。
- **默认零网络、零花费**。只有三件事会联网：模型抽取、归纳、重放旧对话——都需要你显式开启并填 Key。
- API Key 优先读环境变量 `DSH_MEMORY_API_KEY`；写进配置文件时权限 0600，界面只显示尾号。
- 没有任何遥测。

## 怎么开始用

1. 装好后打开 DSH 设置页 →「记忆库」。
2. 第一件事只在「配置」tab：选记忆库目录（点按钮选，不用手打）；需要自动抽取再填 Key、打开开关。
3. 日常不用管它：聊就行。想查以前说过什么，直接问助手「上次关于 X 是怎么说的」。
4. 想备份：维护 tab 点「导出」，选保存位置。

## 边界（先说清楚，避免误会）

- 它记的是**你明确表达过的内容**，不会读心；含糊其辞时说「记住：…」最有效。
- 极短确认（只说「对」「可以」）通常不会被抽成事实——上下文不足，容易记错。
- 向量模型首次使用需要下载（约 24 MB）；下载失败不影响使用，只是少了语义检索。
- 目录选择、打开目录、导出对话框目前是 Windows 原生对话框；其他平台会提示不支持。
